**Definición operativa**

Corresponde a niños con limitaciones significativas en la comunicación funcional y la interacción social, que requieren apoyo constante para expresar necesidades, comprender su entorno y adaptarse a cambios.

**Caracterización funcional**

**Comunicación**

- Lenguaje verbal limitado, inconsistente o emergente.
- Uso de palabras aisladas o frases muy simples sin estructura estable.
- Dificultad para generalizar el lenguaje en distintos contextos.
- Alta dependencia de apoyos externos para comunicarse (visual, gestual o mediado).

**Interacción social**

- Baja frecuencia social.
- Respuestas sociales presentes pero reducidas o poco sostenidas.
- Dificultad para mantener atención conjunta.
- Interacción más reactiva que proactiva.

**Conductas y rigidez**

- Presencia frecuente de conductas repetitivas (motoras o verbales).
- Fuerte apego a rutinas y secuencias específicas.
- Resistencia moderada a alta frente a cambios no anticipados.

**Regulación emocional**

- Dificultades para expresar emociones de forma clara.
- Episodios de frustración ante fallas comunicativas.
- Dependencia del adulto para interpretar estados emocionales.

**Implicancias para desarrollo del sistema**

- Necesidad de estructuras predecibles de interacción.
- Relevancia de reducción de carga cognitiva.
- Importancia de asistencia progresiva en la comunicación.
- Requerimiento de monitoreo continuo del progreso.
- Alta sensibilidad a contexto (rutina, entorno, personas).

**1\. Principios de diseño del sistema**

1.1 Predictibilidad estructural

- Interfaces con patrones repetitivos y consistentes.
- Navegación sin cambios abruptos.
- Secuencias de interacción estables (seleccionar → confirmar → comunicar).

  1.2 Reducción de carga cognitiva

- Máximo 4-6 elementos visibles por pantalla.
- Eliminación de estímulos irrelevantes.
- Uso de jerarquías visuales claras.

  1.3 Contextualización

Adaptación al entorno inmediato: Rutinas, Personas, Lugares y Momentos del día

**2\. Diseño funcional basado en pictogramas**

2.1 Estructura del sistema de pictogramas

**Organización jerárquica**

Nivel 2: Subcategorías (dentro de "Quiero" → comida, actividades, objetos)

**Tipología de pictogramas**

- Pictogramas concretos (objetos reales)
- Pictogramas emocionales
- Pictogramas de acción
- Pictogramas sociales

  2.2 Flujo de comunicación

Flujo base (Nivel 2)

Selección de intención (Quiero)

Selección de elemento (agua)

Confirmación visual/auditiva

Output comunicativo

2.3 Construcción progresiva de comunicación

Nivel inicial: selección única (1 pictograma)

Nivel intermedio: combinación guiada (2 pictogramas)

Nivel avanzado: secuencia estructurada (3+ pictogramas)

**3\. Adaptación a comportamiento del usuario**

3.1 Motor de adaptación

**Debe considerar:**

- Frecuencia de uso
- Contexto temporal (hora/día)
- Rutinas recurrentes
- Historial de selección

  3.2 Priorización dinámica

**Mostrar primero:**

- Pictogramas más usados
- Pictogramas contextualmente relevantes
- Reducir opciones irrelevantes

  3.3 Aprendizaje progresivo

**Ajuste automático de dificultad:**

- Menos opciones → más opciones
- Más asistencia → menos asistencia

**4\. Gestión de interacción social**

Prompts visuales (¿Qué quieres?)

Activación contextual (hora de comida)

4.1 Respuesta asistida

Refuerzo inmediato tras selección

Confirmación clara del mensaje emitido

**5\. Manejo de rigidez y rutinas**

5.1 Integración de rutinas

Pantallas específicas por contexto:

Casa, Escuela, Terapia…

5.2 Anticipación de eventos

**Secuencias predecibles:**

Primero → luego

Reducción de ansiedad ante cambios

**6\. Regulación emocional**

6.1 Módulo emocional

**Pictogramas de emociones básicas:**

Feliz, triste, enojado, cansado

6.2 Canal de emergencia

Acceso rápido a: Dolor, Hambre, Malestar

**7\. Interfaz de usuario (UI/UX)**

7.1 Requisitos visuales

- Alto contraste
- Iconografía clara
- Sin sobrecarga visual

  7.2 Interacción

- Toques grandes y simples
- Feedback inmediato (visual + auditivo)
- Evitar navegación profunda

**8\. Sistema de seguimiento (para cuidadores y terapeutas)**

8.1 Variables a registrar

- Frecuencia de uso
- Tipos de mensajes
- Tiempo de interacción
- Evolución comunicativa

  8.2 Outputs

- Reportes simples y accionables
- Identificación de patrones
- Alertas de progreso o estancamiento

**9\. Requisitos técnicos clave**

- Arquitectura modular
- Base de datos adaptable por usuario
- Capacidad offline (uso en distintos entornos)
- Sincronización entre actores (familia - profesionales)
- Seguridad de datos (información sensible)

**10\. Resultado esperado del diseño**

**Un sistema que:**

- Facilite comunicación funcional inmediata
- Reduzca frustración del usuario
- Se adapte progresivamente al desarrollo del niño
- Mejore la coordinación entre actores
- Genere datos útiles para intervención
